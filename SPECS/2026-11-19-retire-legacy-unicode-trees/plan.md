```python
def parse_bp5_strongs(path: Path) -> tuple:
    """Return (with_parsing, without_parsing) for one `source/Strongs` file."""
    buc = _buc()
    with_parsing = {}
    without_parsing = {}
    for lineno, line in enumerate(path.read_text(encoding="utf-8").splitlines(), 1):
        if not line.strip():
            continue
        match = BP5_RE.match(line)
        if not match:
            raise ValueError(f"unmatched .BP5 line in {path.name}:{lineno}: {line[:80]}")
        key = (int(match.group(1)), int(match.group(2)))
        body = (match.group(3) or "").strip()
        with_parsing[key] = buc.convert_beta_to_unicode_strongs(body, False)
        without_parsing[key] = buc.convert_beta_to_unicode_strongs(body, True)
    return with_parsing, without_parsing
```

```python
def build_current(edition, edition_dir=None):
    edition_dir = edition_dir or editions.edition_dir(edition["id"])
    source = edition_dir / "source"
    books = []
    for cct_file in sorted((source / "CCAT").glob("*.TXT")):
        abbr = _abbr_for(cct_file)                 # loud if unknown
        write_csv(edition_dir / "csv" / "accented" / "no-variants" / f"{abbr}.csv",
                  parse_cct_current(cct_file, drop_variants=True))
        write_csv(edition_dir / "csv" / "accented" / "with-variants" / f"{abbr}.csv",
                  parse_cct_current(cct_file, drop_variants=False))
    for bp5_file in sorted((source / "Strongs").glob("*.BP5")):
        abbr = _abbr_for(bp5_file)
        with_parsing, no_parsing = parse_bp5_strongs(bp5_file)
        write_csv(edition_dir / "csv" / "strongs" / "with-parsing" / f"{abbr}.csv",
                  with_parsing)
        write_csv(edition_dir / "csv" / "strongs" / "no-parsing" / f"{abbr}.csv",
                  no_parsing)
        write_csv(edition_dir / "csv" / "unaccented" / f"{abbr}.csv", no_parsing)
        books.append((abbr, paths.ABBR_TO_BOOK_ID[abbr], no_parsing))
    books.sort(key=lambda item: editions.BOOK_ORDER.index(item[0]))
    for abbr, book_id, verses in books:
        write_tei(edition_dir / "tei" / "unaccented" / f"{abbr}.xml",
                  [(abbr, book_id, verses)])
    write_tei(edition_dir / "tei" / "unaccented" / "BYZ" / "byz.xml",
              books, combined=True)
    write_accented_tei(edition, edition_dir=edition_dir)
```

  Constraints this body encodes, each of which is required for byte identity:
  - `_abbr_for(path)` takes the text between the `NN_`/`NNx_` prefix and the
    suffix (`01_MAT.TXT` -> `MAT`, `04a_PA.TXT` -> `PA`) and raises
    `ValueError(f"unknown book in {path}")` when the abbreviation is not in
    `paths.ABBR_TO_BOOK_ID`. It does **not** use
    `sources.OFFICIAL_TO_ABBR`, which maps official codes (`MT`, `MR`, ...) and
    would reject `MAT`. `source/CCAT` today holds exactly the 27 books plus
    `PA`/`ACT24` and `source/Strongs` exactly the 27 books; any new file is a
    loud failure, not a silent skip (R1.2).
  - `csv/unaccented` is written from the **same dict** as
    `csv/strongs/no-parsing`, so the identity in R8.1 is structural.
  - the unaccented TEI is written **without** `edition_label`, so every file
    keeps the source header block `<edition n="2018">Last updated (XML version)
    <date>31.5.2023</date></edition>`. Passing the curated label changes 28
    files.
  - the combined `BYZ/byz.xml` is in canonical book order
    (`paths.BOOK_ORDER`: MAT, MAR, LUK, ... REV), because that is what the
    legacy converter emitted. `write_accented_tei` keeps its own alphabetical
    (`sorted(glob)`) order; the two views are allowed to differ, and changing
    either would change edition bytes.
  - `books` is built from the Strong's loop, so the unaccented TEI covers the 27
    canonical books and no `PA`/`ACT24` (they have no `.BP5`).
